# 阶段二：记忆与项目管理

## 状态说明

| 标记 | 含义 | 使用条件 |
|------|------|----------|
| `[ ]` | 未完成 | 默认状态；对应开发、测试或验收事项尚未完成 |
| `[X]` | 已完成 | 开发项已核对实现并通过必要的开发方验证；测试项已执行通过；验收项已获用户明确确认通过 |
| `[>]` | 延后开发 | 已确认需要，但不在当前版本实现 |
| `[-]` | 不涉及 | 已确认当前方案不需要实现 |

记录验证结果、环境和未覆盖项；阶段验收须经用户明确确认。以 [PRD](../prd/PRD.md) 和 [开发方案](../solution/开发方案.md) 为准。

## 开发
- [X] 实现记忆列表、详情、更新、软删除、恢复、永久删除和修改历史；永久删除要求先软删除及明确确认。
- [X] 实现项目详情、改名、仓库绑定与解绑；支持无 Git 项目后续绑定仓库。
- [X] 实现知识库列表、创建、改名、类型/归属变更和删除；默认库不可删除或改变类型/归属，普通项目库可改为共享库或迁移到其他项目，删除知识库前需确认。
- [X] 实现标签保存、修改和搜索/列表筛选；Skill 可提交 Agent 建议标签，脚本在交互确认时展示标签。
- [X] 项目合并规则采用原子移动全部源项目库和记忆、保留目标默认库、记录合并操作；删除项目需确认。冲突决策见[设计记录](../待确认问题.md)。
- [X] 实现 mem-list、mem-update、mem-delete 脚本/Skill；目标不明确时 Skill 要求先选择，不执行永久删除。
- [X] 记忆更新、删除、恢复及永久删除通过事务/FTS 触发器保持数据与索引一致；项目和知识库删除也清理关联索引。

## 开发方验证记录

- Go 1.24 Alpine 容器中运行 `go test ./...`、`go vet ./...`、`go build ./cmd/server` 均通过；新增 SQLite 行为测试覆盖记忆生命周期/FTS、标签历史与筛选、项目绑定/解绑、知识库范围变更、项目合并数据保留及项目删除索引清理。
- 独立复审指出列表遍历时嵌套查询死锁、默认库可被移出项目及按 ID 缺少项目范围。修正为单 SQL 标签聚合；以生产 `MaxOpenConns(1)` HTTP 测试回归；默认库类型/归属变更返回 409，普通库可转共享或迁移且默认标记保持；列表、详情、历史、更新、删除均校验项目范围，跨项目回归测试通过。
- `sh -n scripts/*.sh` 和 `git diff --check` 通过。Pi/Codex 的 mem-save/mem-search Skill 已完成本机 Secure 提案、自动化 CLI 审批及检索回读；其他管理 Skill、真人逐次审批及部署身份隔离仍未通过验收。
