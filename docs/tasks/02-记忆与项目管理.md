# 阶段二：记忆与项目管理

## 状态说明

| 标记 | 含义 | 使用条件 |
|------|------|----------|
| `[ ]` | 未完成 | 默认状态；对应开发、测试或验收事项尚未完成 |
| `[X]` | 已完成 | 开发项已核对实现并通过必要的开发方验证；测试项已执行通过；验收项已获用户明确确认通过 |
| `[>]` | 延后开发 | 已确认需要，但不在当前版本实现 |
| `[-]` | 不涉及 | 已确认当前方案不需要实现 |
| `[~]` | 已过时或被替代 | 不再作为当前完成条件；注明原因、原验证状态及适用的替代项 |

记录验证结果、环境和未覆盖项；阶段验收须经用户明确确认。以 [PRD](../prd/PRD.md) 和 [开发方案](../solution/开发方案.md) 为准。

## 开发
- [ ] 实现记忆列表、详情、更新、软删除、恢复、永久删除和必要的修改历史。
- [ ] 实现项目详情、编辑、仓库绑定与解绑；支持无 Git 项目后续绑定仓库。
- [ ] 实现知识库管理，明确类型和项目归属，变更类型或归属须由用户明确操作。
- [ ] 实现标签保存、修改和筛选；支持 Agent 建议标签及用户指定或修改。
- [ ] 明确项目合并冲突规则并实现合并及必要操作记录；项目删除需确认。
- [ ] 实现 mem-list、mem-update、mem-delete；目标不明确时要求用户选择。
- [ ] 保持记忆变更、删除和恢复后的搜索索引一致。
## 测试
- [ ] 测试记忆管理、修改历史及对应搜索结果。
- [ ] 测试知识库类型、归属变更和标签管理，确认标签不改变访问范围。
- [ ] 测试仓库迁移绑定、合并冲突、删除确认及项目隔离。
- [ ] 验证更新和删除均由用户明确触发。
## 验收
- [ ] 用户确认记忆和项目管理满足阶段要求。
