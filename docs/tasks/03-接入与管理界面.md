# 阶段三：接入与管理界面

## 状态说明

| 标记 | 含义 | 使用条件 |
|------|------|----------|
| `[ ]` | 未完成 | 默认状态；对应开发、测试或验收事项尚未完成 |
| `[X]` | 已完成 | 开发项已核对实现并通过必要的开发方验证；测试项已执行通过；验收项已获用户明确确认通过 |
| `[>]` | 延后开发 | 已确认需要，但不在当前版本实现 |
| `[-]` | 不涉及 | 已确认当前方案不需要实现 |
| `[~]` | 已过时或被替代 | 不再作为当前完成条件；注明原因、原验证状态及适用的替代项 |

记录验证结果、环境和未覆盖项；阶段验收须经用户明确确认。以 [PRD](../prd/PRD.md) 和 [开发方案](../solution/开发方案.md) 为准。

## 开发
- [ ] 实现复用业务逻辑的 Streamable HTTP MCP 及 PRD 所列工具。
- [ ] 实现 Web 首页、项目及记忆管理、搜索和系统状态。
- [ ] 实现 Web 的仓库绑定及记忆删除、恢复；界面兼容移动端。
- [ ] 支持在 Web 创建和管理项目库及共享库、选择保存和查询目标、管理标签并展示结果来源；MCP 支持指定库及返回来源。
## 测试
- [ ] 验证 Codex、Pi 的 Skill 和 MCP 实际接入、触发方式及权限行为，并记录版本和环境。
- [ ] 验证 Web 主要操作、项目隔离和移动端布局。
- [ ] 验证 Skill、MCP 和 Web 的知识库选择、共享查询和标签操作。
## 验收
- [ ] 用户确认 MCP 接入和 Web 管理满足阶段要求。
