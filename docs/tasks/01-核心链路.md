# 阶段一：核心链路

## 状态说明

| 标记 | 含义 | 使用条件 |
|------|------|----------|
| `[ ]` | 未完成 | 默认状态；对应开发、测试或验收事项尚未完成 |
| `[X]` | 已完成 | 开发项已核对实现并通过必要的开发方验证；测试项已执行通过；验收项已获用户明确确认通过 |
| `[>]` | 延后开发 | 已确认需要，但不在当前版本实现 |
| `[-]` | 不涉及 | 已确认当前方案不需要实现 |
| `[~]` | 已过时或被替代 | 不再作为当前完成条件；注明原因、原验证状态及适用的替代项 |

记录验证结果、环境和未覆盖项；阶段验收须经用户明确确认。以 [PRD](../prd/PRD.md) 和 [开发方案](../solution/开发方案.md) 为准。

## 开发
- [ ] 确定首阶段接口、错误格式、搜索样例和用户触发写入的授权边界。
- [ ] 初始化 Go 服务、配置、健康检查、SQLite、外键和版本化迁移；按实际环境确定 WAL 和忙等待。
- [ ] 实现项目及仓库映射，识别 Git 子目录和 worktree；处理多个 remote 的歧义。
- [ ] 规范化 SSH、HTTPS 和 SSH URL，处理端口及路径大小写，剔除凭证。
- [ ] 无 Git 或 remote 时默认使用当前文件夹名，允许修改、创建或选择项目并绑定目录；同名时由用户选择。
- [ ] 实现项目库、共享库创建及默认项目库；记忆默认保存至当前项目默认库，也可明确指定目标库，歧义时由用户选择。
- [ ] 实现记忆创建和跨库搜索 API，默认搜索当前项目所有项目库及所有共享库；支持指定库并返回来源，包含输入校验和基本错误处理。
- [ ] 实现 FTS5 搜索、短词匹配、知识库范围和状态过滤、结果数量及长度限制。
- [ ] 实现 mem-save 和 mem-search Skill，并在真实客户端打通调用。
## 测试
- [ ] 测试仓库地址归一化、凭证剔除、不同项目隔离和 remote 歧义。
- [ ] 测试无 Git 项目的默认名称、修改、同名选择和跨设备绑定。
- [ ] 测试默认和指定保存、默认及指定库查询、来源标识、共享库跨项目可见和其他项目库默认隔离。
- [ ] 测试中文短词、英文缩写、中英文混合及多关键词搜索。
- [ ] 验证用户触发保存、真实客户端检索和服务重启后的持久化。
- [ ] 运行 Go 测试并记录结果；具备条件时提前验证 Docker 数据持久化。
## 验收
- [ ] 用户确认真实客户端完成项目库和共享库保存与检索，且重启后数据保留。
