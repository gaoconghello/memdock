# 阶段四：部署、安全与交付

## 状态说明

| 标记 | 含义 | 使用条件 |
|------|------|----------|
| `[ ]` | 未完成 | 默认状态；对应开发、测试或验收事项尚未完成 |
| `[X]` | 已完成 | 开发项已核对实现并通过必要的开发方验证；测试项已执行通过；验收项已获用户明确确认通过 |
| `[>]` | 延后开发 | 已确认需要，但不在当前版本实现 |
| `[-]` | 不涉及 | 已确认当前方案不需要实现 |
| `[~]` | 已过时或被替代 | 不再作为当前完成条件；注明原因、原验证状态及适用的替代项 |

记录验证结果、环境和未覆盖项；阶段验收须经用户明确确认。以 [PRD](../prd/PRD.md) 和 [开发方案](../solution/开发方案.md) 为准。

## 开发
- [ ] 完成 Docker 多阶段构建、非 root 运行、Compose、健康检查和数据持久化。
- [ ] 实现 Private 和 Secure 模式、认证授权及必要配置校验；接入可信 HTTPS。
- [ ] 落实自动读取与写入权限隔离及用户明确授权流程；保护 Web 和 API。
- [ ] 实现 SQLite 一致性备份、下载、恢复前验证及恢复结果检查。
- [ ] 编写配置、Tailscale、反向代理、备份恢复和运行说明。
## 测试
- [ ] 验证 Tailscale 多设备访问、容器重建持久化及备份恢复。
- [ ] 验证只读权限拒绝写入、Secure 模式缺失配置时拒绝启动、HTTPS 和日志脱敏。
- [ ] 验证共享库写入同样需要明确授权，默认查询不会泄露其他项目库。
- [ ] 验证 AMD64 和 ARM64 构建及适用环境运行情况。
## 验收
- [ ] 用户确认部署、安全和备份恢复满足阶段要求。
