# MemDock

MemDock 是一个面向 Coding Agent 的轻量级共享长期记忆服务，帮助用户在不同会话、设备和 Agent 之间保存与检索项目经验。

**核心原则：用户明确决定保存什么，Agent 根据任务按需检索。**

## 项目状态

项目目前处于规划阶段，尚无可运行的服务、安装包或构建命令。本文中的功能和部署方式均为规划内容。

## 主要功能

- **项目识别**：通过 Git Remote 识别项目；没有 Git 或 Remote 时，默认以当前文件夹名作为项目名称，由用户选择或创建并绑定项目。
- **项目库和共享库**：支持多个知识库。项目库绑定项目，共享库供多个项目查询；用户可以指定记忆的保存位置。
- **按需检索**：默认查询当前项目的项目库和所有共享库，结果标明来源；支持指定知识库、中文和英文关键词。
- **记忆管理**：用户明确触发保存、更新和删除；支持分类、标签、恢复及必要的修改历史。Agent 可以建议标签。
- **多种接入**：计划优先通过 Skill 接入，同时提供 MCP、HTTP API 和 Web 管理界面。
- **自行部署**：计划使用 Go、SQLite 和 Docker，支持数据持久化、备份恢复及网络访问控制。

## 开发计划

1. **核心链路**：项目识别、知识库、记忆保存和搜索，以及基础 Skill。
2. **记忆与项目管理**：补齐记忆、知识库、标签和项目管理。
3. **接入与管理界面**：实现 MCP、Web Console，并验证客户端接入。
4. **部署、安全与交付**：完成 Docker、网络部署、认证授权及备份恢复。
5. **整体验收**：验证跨设备、项目隔离、搜索、安全和性能。
